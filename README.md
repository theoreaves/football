
Team settings now include an optional **Specialists** tab for the latest roster:
third-down/short-yardage back, kick returner and punt returner. Empty slots retain
normal selection. The situational back applies on all third downs and with two
or fewer yards to go during offensive scrimmage plays; a manual game RB choice
wins. Injured or fatigued specialists fall back to normal personnel. Assignments
are captured with new game rosters and do not alter saved games or replays.

Individual personnel changes animate between plays, retaining players who stay
in the lineup on the field. Manual changes and injury/fatigue replacements share
the existing Skip player change control. In the same browser tab, a submitted
call also carries the current visible lineup into a substitution animation
before breaking the next huddle when the actual play needs different personnel.
These presentation seconds never advance the simulation clock. Formation-based
personnel packages and planned RB/receiver rotation are described in
[personnel-rotation.md](docs/personnel-rotation.md).

Human play-calling review screens include searchable one-play personnel replacements.
See [one-play-personnel.md](docs/one-play-personnel.md) for supported plays, selection priority, and replay behavior.

Season team pages include **Team Plays**: named offensive/defensive variations with optional cross-position personnel. See [team-plays.md](docs/team-plays.md) for capture and play-calling behavior.
